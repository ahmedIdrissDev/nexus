# Nexus UI Library

## Purpose

Nexus is a UI design skill for AI coding agents.

## Instructions

1. Inspect the existing project and read `styles/globals.css`.
2. Apply the Nexus global styles without overwriting unrelated application styles.
3. Discover reusable primitives in `components/ui/` and examples in `references/`.
4. Copy only the required TSX files and update imports for the consuming project.
5. Install the runtime dependencies required by the selected components: React, `tailwind-merge`, `lucide-react`, and, for Next.js examples, `next`.
6. Preserve existing application logic and validate TypeScript and build checks.

The files in this skill are the source of truth for the Nexus visual design. Do not alter CSS declarations, selectors, design tokens, Tailwind classes, or component visual behavior when integrating them.
